## 오늘 새로 쓴 명령

- `requests.post(URL, headers=headers, json=body, timeout=30)`: 프롬프트를 담은 LLM API 요청
- `json.loads(clean)`: LLM이 반환한 JSON 문자열 파싱
- `importlib.reload(llm_client)`: 수정한 모듈을 노트북에 다시 반영
