## 오늘 새로 쓴 명령

- `requests.get(url, params=..., headers=..., timeout=...)`: 조회 조건·헤더·대기 제한을 지정한 API 요청
- `response.raise_for_status()`: HTTP 오류 응답을 예외로 처리
- `call_with_retry(url, tries=3)`: 실패 시 횟수를 제한해 재시도하는 실습 함수

## 찾아보고 알게 된 것

- API 요청은 응답 내용뿐 아니라 HTTP 상태와 연결 실패를 함께 처리해야 함. `timeout`과 `raise_for_status()`로 실패를 구분
- 재시도 횟수를 제한하고, API 조회 로직을 함수로 묶어 결과를 파일에 남기는 클라이언트 구성
