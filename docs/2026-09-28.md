## 오늘 새로 쓴 명령

- `try` / `except` / `finally`: 예외 유형별 처리와 공통 마무리
- `logging.basicConfig(...)`, `logging.warning(...)`, `logging.error(...)`: 심각도에 따른 로그 기록
- `json.dumps()` / `json.loads()`, `json.dump()` / `json.load()`: 문자열 변환과 파일 저장·읽기 구분

## 찾아보고 알게 된 것

- 잘못된 로그 한 줄이 전체 처리를 멈추지 않도록 예외를 구분하고, 실패 원인은 로그로 남기기
- 로그의 필드와 자료형을 공통 구조로 정규화하면 원본 형식이 달라도 같은 집계 로직을 적용할 수 있음
- 중첩된 리스트·딕셔너리를 JSON으로 저장해 다음 처리 단계에서 재사용
