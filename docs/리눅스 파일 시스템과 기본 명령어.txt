함수(Function)와 메서드(Method)의 차이
- 함수와 메서드의 가장 큰 차이는 특정 객체나 클래스에 소속되어 있는지 여부이다.

함수(Function): 특정 객체에 소속되지 않고 독립적으로 호출할 수 있는 기능
메서드(Method): 클래스나 객체에 소속되어 해당 객체를 통해 호출하는 함수

- 함수
함수이름()
-----------------
- 메서드
객체.메서드이름()

# 함수(Function)는 독립적으로 호출하는 기능이고, 메서드(Method)는 객체나 클래스에 소속되어 호출하는 함수이다.

---------------------------------------------------------------------------------------------------------

1. 디렉토리 (Directory)
• 정의: 운영체제가 파일을 관리하기 위해 파일의 위치 정보를 기록해 둔 '목록' 또는 '주소록' 같은 개념입니다.
• 특징: 명령 프롬프트(CLI, 예: MS-DOS, 리눅스 터미널) 환경에서 주로 사용되는 용어입니다. 실제 하드디스크나 SSD 같은 저장 장치의 파일 구조와 직접 연결되어 있습니다.

2. 폴더 (Folder)
• 정의: 마이크로소프트 윈도우나 맥OS 같은 그래픽 화면에서 종이 서류철(Folder)을 비유해 만든 시각적 객체입니다.
• 특징: 디렉토리를 포함하는 개념이면서 동시에 가상 폴더까지 아우릅니다.
• 가상 폴더의 예: 윈도우의 '제어판', '네트워크', '휴지통' 등은 실제 하드디스크 상의 특정 디렉토리 경로에 파일로 존재하는 것이 아니라, 시스템 기능들을 모아둔 가상 공간인데 이를 '폴더'라고 부릅니다.



절대 경로 (Absolute Path)
• 정의: 최상위 디렉토리(루트)에서 시작해 파일이나 폴더가 가진 고유한 전체 주소를 나타냅니다.
• 특징: 윈도우는 C:\, 리눅스나 맥은 / (루트)로 시작합니다.
• 장점: 내가 어디에 있든 항상 정확한 위치를 가리키므로 경로를 찾지 못할 확률이 낮습니다.
• 단점: 주소가 길고 복잡하며, 폴더나 파일의 위치가 바뀌면 경로를 모두 수정해야 합니다.

상대 경로 (Relative Path)
• 정의: 현재 내가 작업하고 있는 폴더(현재 디렉토리)를 기준으로 목적지의 위치를 나타냅니다.
• 특징: 현재 위치는 ., 상위(부모) 폴더는 .. 기호를 사용합니다. 슬래시(/)로 시작하지 않습니다.
• 장점: 주소가 짧고 간결하며, 프로젝트 전체 폴더를 다른 위치로 통째로 옮겨도 상대적인 위치가 같다면 수정할 필요가 없습니다.
• 단점: 현재 내 위치가 어디인지 정확히 모르면 올바른 경로를 작성하기 어렵습니다.


홈 디렉토리란?
• 개인 공간: 사용자의 파일, 설정, 문서 등이 저장되는 독립된 장소입니다.
• 기본 위치: 리눅스에서 사용자가 로그인하면 처음으로 위치하게 되는 기본 디렉토리입니다.
• 경로: 보통 리눅스에서는 /home/사용자아이디 형태를 가집니다. (예: 아이디가 eisen이면 /home/eisen)
주요 특징
• ~ (틸드) 기호: 현재 사용자의 홈 디렉토리를 가리키는 단축키(별칭) 역할을 합니다.
• 보안: 각 사용자마다 권한이 설정되어 있어 리눅스 파일 시스템 구조에서 타인의 접근이나 수정 등을 제한할 수 있습니다.


기본 명령어
• pwd (Print Working Directory): 현재 내가 위치한 디렉토리의 전체 경로(절대 경로)를 화면에 보여줍니다.
사용법: pwd

• ls (List): 현재 디렉토리에 포함된 파일과 폴더 목록을 확인합니다. (-l, -a 등의 옵션과 함께 자주 쓰입니다.)
사용법: ls 또는 ls -l

• cd (Change Directory): 다른 디렉토리로 이동할 때 사용합니다. (cd ..을 입력하면 상위 디렉토리로 이동합니다.)
사용법: cd [이동할_디렉토리_이름]

• mkdir (Make Directory): 새로운 디렉토리(폴더)를 생성합니다.
사용법: mkdir [생성할_디렉토리_이름]
