## 찾아보고 알게 된 것
저장소 관계: 깃허브 저장소와 내 PC의 폴더는 명령어(Git)로 연결되어 코드를 백업하고 내려받는 '클라우드와 내 컴퓨터의 쌍둥이 저장소' 관계

• 내 PC의 폴더 (로컬 저장소, Local Repository): 내 컴퓨터에 직접 존재하는 폴더로, .git이라는 숨겨진 기록 파일이 포함되어 있어 실시간으로 코드를 수정하고 저장(커밋)하는 공간

• 깃허브의 저장소 (원격 저장소, Remote Repository): GitHub 같은 온라인 서버에 존재하는 저장소로, 내 컴퓨터의 작업 기록을 안전하게 백업하고 다른 사람과 공유하는 공간

원격 저장소의 이름: 내 PC에서 깃허브 저장소를 가리키는 기본 별명은 origin
