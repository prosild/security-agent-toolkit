## 오늘 새로 쓴 명령

- `re.search(...)`, `re.findall(...)`: 로그 패턴의 첫 일치와 전체 일치 검색
- `(?P<이름>...)`, `.groupdict()`: 이름 붙인 그룹으로 로그 필드를 추출해 딕셔너리로 변환

## 찾아보고 알게 된 것

- 위치에 의존하는 `split` 대신 패턴으로 로그를 정규화하고, 일치하지 않는 줄은 별도 파일에 보관
- 계정별 반복 실패, IP별 실패, 심야 로그인 성공을 서로 다른 탐지 기준으로 구성
- HTTP 401은 인증 정보, 403은 접근 권한 문제를 우선 확인. API 요청의 인증 방식도 함께 점검
