## 6교시 · 코드로 계산과 판정

### 문제 6-1 · 지터 함수 직접 만들기

- (가) 직접 만든 `jitter` 함수를 독스트링과 함께 아래 코드 블록에 붙여 넣어 주세요.
  - 쓸 내용: 독스트링을 쓴 함수를 복사해 아래 코드 블록에 붙여 넣기
  - 답: 
``` python
def jitter(got):
    total = 0
    for idx in range(1, len(got)):
        total = abs(got[idx - 1] - got[idx])

    return total / len(got) -1
```

- (나) 함수를 채운 뒤 실행해 나온 세 줄을 그대로 옮겨 적어 주세요.
  - 쓸 내용: 터미널 출력 세 줄을 복사해 붙여 넣기
  - 답: 
회선 A | 지연 21.9 ms | 지터 -0.9 ms | 손실 0 %
회선 B | 지연 42.3 ms | 지터 6.5 ms | 손실 0 %
회선 C | 지연 41.0 ms | 지터 -0.6 ms | 손실 30 % 
- (다) `jitter` 함수의 리턴값은 무엇이고, `measure` 의 어느 줄에서 어떻게 쓰이나요?

  - 쓸 내용: ① 「사내 / 바깥」 하나 ② 근거(사내 홉의 시간 또는 장비 이름)

  - 쓸 내용: ① 4번 홉의 뒤 홉 시간 ② 그것이 무엇을 뜻하는지
  - 답: 4번 홉만 60ms로 크고 다음 5번 홉이 7ms로 다시 작아짐, 뒤쪽 홉이 작은 것은 4번 장비가 지나가는 패킷은 빨리 넘겼다는 뜻, 4번 장비가 자기 응답만 늦게 만든 것이라 실제 장애가 아님
